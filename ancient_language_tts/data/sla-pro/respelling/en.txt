The jers are pronounced. Do not delete /ɪ/ or /ʊ/. /ẽ/ and /õ/ are nasal nuclei: the n in ehn and ohn is the nasal, not a separate consonant. /w/ is w, including where the source wrote v. /g/ is g.

Vowels
- /i/ → ee
- /ɨ/ → ih'uh, one syllable. A stressed one is IH'UH.
- /ɪ/ → ih
- /e/ → eh
- /æ/ → ae
- /ɑ/ → ah
- /o/ → oh
- /u/ → oo
- /ʊ/ → uh
- /ẽ/ → ehn, the whole nucleus
- /õ/ → ohn, the whole nucleus
- /r̩/ → er, /l̩/ → el, each a whole syllable

Consonants
- /p b t d k g s z m n l r/ → the same letters
- /j/ → y
- /w/ → w
- /x/ → kh
- /ʃ/ → sh
- /ʒ/ → zh
- /tʃ/ → ch
- /ts/ → ts, one onset or one coda
- /lʲ/ → ly, /nʲ/ → ny, /rʲ/ → ry, each in the same syllable as the vowel. The y marks the palatal consonant and does not start a new syllable.
