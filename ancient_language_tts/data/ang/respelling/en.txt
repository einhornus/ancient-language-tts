The source letter c is already /tʃ/ or /k/ in the IPA. Spell the sound, not the letter: /tʃ/ is ch, /k/ is k, /ʃ/ is sh even when the source wrote sc. /y/ is ee.

Vowels
- /ɑ/ /ɑː/ → ah
- /æ/ /æː/ → ae
- /e/ → eh
- /eː/ → ey
- /i/ /iː/ → ee
- /o/ → aw
- /oː/ → oh
- /u/ → uh
- /uː/ → oo
- /y/ /yː/ → ee
- /æɑ/ /æːɑ/ → ae'ah, one syllable. A stressed one is AE'AH.
- /eo/ → eh'aw, one syllable
- /eːo/ → ey'oh, one syllable
- /iy/ /iːy/ → ee

Consonants

- /tʃ/ → ch
- /dʒ/ → j
- /ʃ/ → sh
- /j/ → y
- /ɣ/ → gh
- /θ/ /ð/ → th
- /x/ /ç/ → kh

- /ʍ/ → hw
- /l̥/ → hl, /r̥/ → hr, /n̥/ → hn, each one onset
