Map each IPA symbol to the English spelling. Aspirated stops stay stops: φ θ χ are never f, th, or kh. /y/ becomes ee so that it stays distinct from ου, which is oo.

Vowels
- /a/ /aː/ → ah
- /e/ → eh
- /ɛː/ → ey
- /i/ /iː/ → ee
- /o/ → oh
- /ɔː/ → aw
- /y/ /yː/ → ee
- /eː/ → ey
- /uː/ → oo
- /ai/ → eye
- /au/ → ow
- /eu/ → ew
- /oi/ → oy
- /yi/ → ee

Consonants
- /p/ /pʰ/ → p
- /t/ /tʰ/ → t
- /k/ /kʰ/ → k
- /b/ → b
- /d/ → d
- /g/ → g
- /s/ → s
- /z/ → z
- /m/ → m
- /n/ → n
- /ŋ/ → ng
- /l/ → l
- /r/ /r̥/ → r
- /h/ → h
- /j/ → y
- /w/ → w

ζ arrives as /z/ plus /d/ in the same syllable. Write zd plus the nucleus, one syllable: /zd/ plus /e/ is zdeh.
/pʰ tʰ kʰ/ are p t k, never f, th, or kh. The English voice aspirates a stop at the start of a stressed syllable on its own.
